# Data Governance

Classification: Public, Internal, Confidential, Restricted. Field metadata may define masking/export rules.

Each domain owns canonical data quality; MDM governs cross-domain masters. Imported data preserves source system, external ID, run, mapping version and timestamp.

Retention configurable by category/jurisdiction. Distinguish business cancellation, soft-delete configuration, privacy anonymization/deletion, legal retention and tenant offboarding.

Bulk export is permissioned/audited. Data quality includes required/validity rules, duplicates, exception queues, stewardship and reconciliation. During coexistence maintain source-of-truth registry.
