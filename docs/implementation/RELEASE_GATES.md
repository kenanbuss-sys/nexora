# Release Gates

Architecture: capability IDs, owner, no conflict, ADR for deviation. Security: isolation/permission tests, secrets/file review, high-risk controls. Data: migrations, constraints/indexes, idempotency/concurrency, reconciliation. Quality: tests/failure states/observability/performance. UX: role fit/accessibility/loading-error-empty/device/branding. Operations: runbook, alerts, rollback and feature flag where warranted. Critical failure blocks release.
