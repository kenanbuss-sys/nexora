# Enterprise Discovery Checklist

For each prospective implementation review:

- legal entities, branches, warehouses, factories, projects/sites
- products/SKUs/variants/barcodes/UOM/packaging/lots/serials
- B2C, B2B, POS, marketplaces, sales reps
- pricing, contracts, rebates, approvals, credit
- procurement, imports, containers, suppliers, landed cost
- receiving, putaway, replenishment, picking, packing, transfer, inventory
- production types, BOM, formulas, routing, machines, tools, capacity, shifts
- scanners/checkers, QC, scrap/rework, traceability, work instructions
- maintenance, service, warranty, installation, field work
- logistics, couriers, own fleet, route/load/dock/yard
- projects/job costing/subcontractors
- workforce/time/skills/certifications
- finance, budgets, cost centers, cash, AP/AR, accounting/fiscal systems
- documents, approvals, signatures, retention
- CRM/support/cases/knowledge/marketing
- dashboards/KPIs/reports/forecasting
- all current software, APIs, file exchanges, Excel and paper
- users/roles/sensitive data/segregation of duties
- data migration sources/quality/volumes
- offline/network conditions and physical devices
- security/SSO/compliance/data residency requirements
- localization/language/currency/tax/eInvoice
- desired SLA, uptime, backup, recovery and support
- future growth, additional sites/countries/channels

Output: AS-IS map, TO-BE map, capability mapping, integration map, source-of-truth matrix, migration plan, role matrix, implementation waves and acceptance KPIs.
