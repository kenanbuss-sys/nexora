# UX Information Architecture

Experiences: Enterprise Web, Mobile Operations, Shop-floor/Kiosk, B2B Customer Portal, POS, Internal Platform Admin.

Default web navigation is role/tenant configurable: Home/Control Center, Inbox/Tasks/Approvals, CRM, Sales/Quotes, Orders, Products, Procurement, Inventory/Warehouse, Planning, Production, Quality, Maintenance, Service/Field, Logistics, Projects, Workforce, Finance, Analytics, Documents, Integrations, Devices, Administration. Disabled/unauthorized modules are not shown.

Global shell: tenant brand, company/site context, universal search, unified inbox, notifications, quick create, user menu, command palette.

Standard object page: Overview / Activity / Details / Related / Documents / Audit, with domain-specific tabs.

Exception-first dashboards prioritize blocked orders, shortages, late production, failed QC, failed integrations, overdue approvals and stock discrepancies.

Accessibility baseline: keyboard navigation, visible focus, semantic labels, sufficient contrast and non-color-only states.
