# Internal Platform Admin / Configuration Studio

For platform operators/authorized implementers, not ordinary tenant users.

Areas: tenants, custom domains, branding, modules/licenses, organizations, role templates, custom fields/objects, forms, workflows/rules, documents, terminology, dashboards, integrations, devices, feature flags, usage, health, migration jobs, support and release assignment.

High-risk configuration is versioned/publishable and may require approval. Show impact before breaking changes. Cross-tenant support impersonation requires explicit authorization, step-up and audit.
