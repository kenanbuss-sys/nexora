# B2B Customer Portal

Goal: move legal-entity customers from phone/email/manual ordering into self-service.

Company supports buyer, approver, finance viewer, project/site user and admin.
Navigation: Home, Catalog, Configurators, Quotes, Orders, Projects/Sites, Deliveries, Invoices/Documents, Claims/Service, Account/Users.

Configured manufacturing can capture dimensions/options, validate compatibility, calculate price, resolve immutable manufacturing specification/BOM, estimate promise, create quote/order and expose safe production milestones. Confidential cost/BOM details remain hidden unless explicitly permitted.

Catalog, price, credit visibility, documents and workflows are customer/contract policy-driven. Portal user is strictly scoped to own company and permitted projects/sites.
