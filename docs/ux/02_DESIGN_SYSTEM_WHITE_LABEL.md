# Design System & White-Label

Premium enterprise UI, dense enough for work but calm and consistent. Never hardcode tenant colors.

Token groups: surface, text, border, brand, status, spacing, radius, shadow, typography, motion.
Theme layering: neutral defaults -> tenant brand -> accessibility corrections -> user light/dark preference where enabled.

Shared components: actions/forms/data grids/command palette/filters/status/timeline/activity/approval cards/KPI/charts/scanner input/document viewer/audit viewer/workflow status/loading-error-empty.

Enterprise grid: column configuration, saved views, sorting/filtering, keyboard, permissioned bulk actions/export, virtualization when needed.

Tenant uniqueness: brand, app title, navigation, terminology, dashboards, documents, portal shell and emails; shared platform branding need not be visible in tenant-facing surfaces.

Quality: no ambiguous destructive action, no silent failure, progress for long tasks, blocked actions explain why and next permitted step.
