# Extension & Industry-Pack Architecture

Extend without branching core through custom objects/fields, workflow/rule/document/dashboard templates, connectors, devices, event subscribers, approved server actions and UI slots.

Industry pack is a versioned bundle of configuration/templates and optional extension modules; may enable modules/forms/terminology/workflows/KPIs/documents.

Extension rules: never bypass tenancy/permissions, never direct-write another domain, declare capabilities/permissions/events/version compatibility, include upgrade/migration path.
